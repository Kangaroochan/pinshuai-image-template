# 通用经验索引

各模板的经验记在自己的 `templates/<模板名>/lessons.md`，编号各自从 L001 起，引用时写模板名加编号，比如"圣诞珍珠画01 L013"。本文件只登记对所有模板都适用的条目，指向原条目，不复制证据。写提示词前先读这里，再读模板自己的 `lessons.md`。规则见 SKILL.md 的"经验学习"一节。

2026-11-02 圣诞珍珠画01 和 圣诞珍珠画02 两个 skill 合并进本 skill，变成两个模板。合并前的条目里写的"SKILL.md 某一节"，现在分在本 skill 的 SKILL.md（通用规则）和模板的 `说明.md`（模板专属）里；"template/carousel.json"现在是 `templates/<模板名>/carousel.json`。

新的通用经验（不是从某个模板的条目登记过来的）从 G001 编号，格式和状态定义同模板的 `lessons.md`。
